# Wingman 功能审计（2026-11-06）

> 目的：在「全面」的前提下做减法，让工具条有聚焦感。
> 判断标准：**每周会不会用 ≥3 次** × **别处有没有等价物** × **少了它会不会真的不方便**。

---

## 一、总览：11 个标签的一句话定义

| # | 标签 | 一句话定义 | 频次 | 不可替代性 | 建议 |
|---|---|---|---|---|---|
| 1 | 速记 | 不离开对话就能记下便签 / 跟进 / 提醒 | 每天多次 | 高（跨插件复用已有便签墙与跟进系统） | **常驻** |
| 2 | 常用指令 | 存下高频 prompt，点一下插进输入框 | 每天 | 高（保存的是「成品指令」） | **常驻** |
| 3 | 选中文字 | 选中一段文字后，引用 / 改写 / 解释 / 存起来 | 每天 | 高（把「读到的东西」变成「能用的东西」） | **常驻** |

| 6 | 最近文件 | 工作目录最近改过的文件，点击插入 `@路径` | 写代码时每天 | 中（省打字、防路径错） | ⋯ 收纳 |

| 11 | 设置 | 顺序、隐藏、吸附、位置、自定义入口、还原 | 配置时才用 | 高（不给入口就没法调） | 常驻（齿轮） |

## 二、逐个详解

### 1. 速记
- **定义**：对话侧边的随手记入口，三种模式共用一块输入区。
- **功能**：
  - 便签 → 写入便签墙（`dsh-sticky-wall`），可跨会话看到
  - 跟进 → 写入跟进清单（`dsh-followup`），支持自然语言时间
  - 提醒 → 写入本机 `reminders.json`，到点工具条弹一次提示
- **怎么用**：点便签 → 选模式 → 写一句 → Enter（Shift+Enter 换行）→ 右下角按钮。
- **价值**：把「想到就记」的摩擦降到最低；记完的东西仍能在原系统里被引用。
- **风险**：三种模式共用一个输入框，切换时容易带着上一段文字。
- **建议**：保留，常驻。

### 2. 常用指令
- **定义**：可复用的 prompt 库。
- **功能**：存、分组、搜索、按使用次数排序、一键插入、还原为示例。
- **怎么用**：点便签 → 搜或选一条 → 自动插入输入框；右下角「＋」新建。
- **价值**：高频指令不用每次重写；越用越顺手（按使用次数排序）。
- **风险**：与「引用清单」「选中文字 → 存成片段」存在存储重叠。
- **建议**：保留，常驻，并作为「文本复用」的唯一成品库。

### 3. 选中文字
- **定义**：对正文里选中的一段文字做「下一步动作」。
- **功能**：
  - 本地动作：引用到输入框、评论后引用、存便签、存片段、复制、存成跟进
  - AI 动作：改写成指令、提炼要点、解释这段、生成测试用例、译中、译英
- **怎么用**：选中文字 → 点紫色便签 → 选动作 → 结果可插入 / 复制 / 存片段。
- **价值**：把「读到的东西」立刻转成「能发出去的东西」，是工具条里最像「副驾驶」的一项。
- **风险**：AI 动作依赖模型通道，传输失败时会额外出错（已加一次重试与友好提示）。
- **建议**：保留，常驻；本地动作与 AI 动作分两栏展示已经足够。

### 4. 说到哪了（建议合并）
- **定义**：当前会话的「体检摘要」。
- **功能**：3 条结论 / 2 条未决 / 1 条下一步；可插入输入框或存便签。
- **怎么用**：点天蓝便签 → 自动生成 → 需要就插回。
- **价值**：长对话迷路时最快找回线索的方式。
- **风险**：与「接着上次」在输出形态上高度相似，只差输入范围。
- **建议**：与「接着上次」合并为**「会话小结」**，面板内两个按钮：「这轮 / 上个会话」。

### 5. 接着上次（建议合并）
- **定义**：从上一个有内容的会话里接一句话。
- **功能**：跨 6 个候选会话找第一个有文字的，生成一句第一人称开场，≤80 字。
- **怎么用**：新会话开头点琥珀便签 → 插入开场句 → 补一句就能发。
- **价值**：跨天续接工作不用重新回忆。
- **风险**：依赖历史会话质量；空会话已被跳过。
- **建议**：并入「会话小结」。

### 6. 最近文件
- **定义**：工作目录的「最近改动」列表。
- **功能**：扫 60 天内改动（深度 ≤3、跳过 node_modules 等），点一条插入 `@相对路径`。
- **怎么用**：点珊瑚色便签 → 点文件名 → 输入框出现 `@…`。
- **价值**：少打字、防路径写错，尤其适合「AI 都在这几个文件里干活」的场景。
- **风险**：大仓库有扫描上限（4000 条目）；只读。
- **建议**：保留，收进 ⋯；如果「@ 引用文件」在 DSH 里已很好用，可考虑降级为更多里的选项。

### 7. 引用清单（最弱的一项）
- **定义**：自动收集「引用过的段落」。
- **功能**：引用/评论后引用时自动记录；列表可再插回；可清空。
- **怎么用**：平时不用管它，想找回某段引用时点开。
- **价值**：省去「重新选中那段话」的动作。
- **风险**：**只记录通过本插件发生的引用**；与常用指令、便签三处都在存文本，心智负担大。
- **建议**：保留在 ⋯（不删），并考虑下一步「引用 → 直接存成常用指令」，让它成为素材源而非孤岛。

### 8. 会话搜索
- **定义**：跨会话关键词检索。
- **功能**：输入词回车 → 按会话聚合结果 → 点一条插入摘要。
- **怎么用**：点青色便签 → 搜 → 点结果。
- **价值**：找回「上次那个结论」比翻会话快。
- **风险**：依赖宿主全文索引；没有索引时会报错（已转为友好提示）。
- **建议**：保留在 ⋯；建议先自用一周验证命中率，再决定是否常驻。

### 9. 对话状态
- **定义**：当前会话的「仪表盘」。
- **功能**：上下文 token 与占比、模型名、子任务列表、未完成跟进数。
- **怎么用**：点灰色便签 → 看一眼 → 决定是否开新会话 / 压缩。
- **价值**：避免在上下文快满时继续硬聊导致质量下降。
- **风险**：频率低；信息可被「会话小结」部分替代。
- **建议**：保留在 ⋯。

### 10. 自定义入口
- **定义**：把「打开路径 / 运行命令」做成一键便签。
- **功能**：新增、编辑、执行；执行结果回显。
- **怎么用**：设置 ⚙ → 新增入口 → 选类型 → 填路径/命令。
- **价值**：把工具条扩展成「个人动作台」。
- **风险**：需要用户自己配置，非开箱即用。
- **建议**：保留在 ⋯，作为扩展位。

### 11. 设置
- **定义**：工具条自身的控制台。
- **功能**：顺序、隐藏、吸附开关、位置复位、还原工具条、自定义入口管理、版本号。
- **价值**：没有它，任何个性化都做不了。
- **建议**：常驻齿轮，不进 ⋯。

## 三、重叠地图（这是「聚焦感」的关键）

| 重叠点 | 涉及 | 处理建议 |
|---|---|---|
| 「把文字存起来」 | 速记·便签 / 选中文字·存便签 / 引用清单 / 常用指令 | 明确分工：**便签=随手记**，**常用指令=成品**，**引用清单=素材**；不再新增第四个存储入口 |
| 「会话摘要」 | 说到哪了 / 接着上次 | 合并为「会话小结」 |
| 「检索」 | 最近文件 / 会话搜索 | 一个找文件、一个找会话，保留但都放 ⋯ |
| 「AI 动作」 | 选中文字 / 说到哪了 / 接着上次 | 统一走同一个错误提示与重试 |

## 四、推荐方案

### 方案 A（推荐：聚焦版，常驻 4 颗）
```
✎ 速记        ❝ 常用指令      ✦ 选中文字      ▤ 会话小结
⋮ 展开其余（最近文件 / 引用清单 / 会话搜索 / 对话状态 / 自定义入口）
⚙ 设置  🧲 吸附
```
- 常驻只留「每天都会碰」的四颗
- 合并方案：把「说到哪了」+「接着上次」合成「会话小结」（工作量约 1 小时）
- 什么都还在，只是不占视线

### 方案 B（全面版，常驻 6 颗）
```
✎ 速记  ❝ 常用指令  ✦ 选中文字  ▤ 会话小结  ▦ 最近文件  ◔ 对话状态
⋮ 其余（引用清单 / 会话搜索 / 自定义入口）
```
- 适合你「文件与状态也要随手看」的工作方式
- 代价：工具条更长，聚焦感弱一些

### 方案 C（精简版，常驻 3 颗）
```
✎ 速记  ❝ 常用指令  ✦ 选中文字
⋮ 其余全部
```
- 最干净，但「会话小结」这类救急功能会藏得深

## 五、需要你拍板的 5 个问题

1. 「说到哪了」和「接着上次」要不要合并成一个「会话小结」？（推荐：合并）
2. 「引用清单」你实际用过吗？三个月内没点过就留在 ⋯ 别删，删了以后想要还得重做。
3. 「会话搜索」的命中率如何？一周围一次都没搜到有用的，说明宿主索引不适合，应降级或去掉。
4. 「最近文件」你更常用「@ 文件引用」还是它？如果 DSH 原生 @ 已够用，它就没有存在必要。
5. 常驻选 4 颗（方案 A）还是 6 颗（方案 B）？

## 六、总体判断

- **核心价值**：速记、常用指令、选中文字 —— 这三项构成「记下来 → 复用 → 行动」的闭环，是插件存在的理由。
- **救急价值**：会话小结（由两个旧功能合并）—— 长对话与跨天续接时的安全网。
- **扩展价值**：最近文件、会话搜索、引用清单、对话状态、自定义入口 —— 有用但不是每天用，放 ⋯ 即可。
- **风险项**：会话搜索（依赖宿主索引）、引用清单（只记录本插件内的引用）、AI 动作（依赖模型通道稳定性）。

## 七、最终决定（2026-11-06，已实施）

| 决定 | 结果 |
|---|---|
| 合并「说到哪了」+「接着上次」 | ✅ 成「会话小结」，面板内两个按钮 |
| 删除「引用清单」 | ✅ 代码、宿主路由、存储、测试全部移除 |
| 删除「会话搜索」 | ✅ 与 DSH 宿主 `searchSessions` 重叠 |
| 删除「最近文件」 | ✅ 原生 `@` 已覆盖；按修改时间排序价值有限 |
| 常驻 4 颗 | ✅ 速记 / 常用指令 / 选中文字 / 会话小结 |
| ⋯ 收纳 | ✅ 对话状态 + 自定义入口 |

**终态：5 个内置功能 + 自定义入口 + 设置，默认露 4 颗。**
